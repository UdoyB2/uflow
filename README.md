# UFlow

Student planner UI (React 19 + Vite + Tailwind CSS v4), exported from Figma Make.

## Run locally
1. Install Node.js 20+ from https://nodejs.org
2. In this folder:
   npm install
   npm run dev
3. Open http://localhost:5173

## Build for production
   npm run build      (output goes to /dist)
   npm run preview

## Where things are
- src/App.tsx    all pages (login, dashboard, tasks, calendar, reminders, notes, focus, medicine)
- src/index.css  all styling
- public/        favicon and profile image

Note: this is a front-end prototype. Login and data are not connected to a real backend yet.
